# 门户改版验收

本地预览：http://127.0.0.1:3100/，关于页：http://127.0.0.1:3100/about。

## 验证

- `npm run lint`、`npm run typecheck`、`npm run build` 通过。仓库没有既有 test 脚本。
- 浏览器实操三个工具按钮及家长入口，确认导航到指定的四个地址；四个线上地址直接请求均返回 HTTP 200，页面标题与工具名称对应。
- 首页工具定位、进群定位、关于页、跨页面回到首页进群区及“返回工具”通过。
- 在 320、360、390、430、700、701、768、1024、1440 像素宽度检查 `/`、`/about`、`/tools`，无横向溢出或可见文字截断；桌面三张卡片等高，主按钮对齐；手机卡片纵向排列，首个按钮在首屏内。
- 主按钮至少 48 像素高；键盘焦点可见；按钮文字对比度约 5.72:1，正文约 12.68:1，进群说明约 5.38:1。
- `/tools` 继续可访问，工具名称更新后搜索及分类仍可用。
- 正常预览没有浏览器运行时错误。详细布局与导航结果见 `checks.json`。
- 使用隔离浏览器内临时注入的现有清单插画，测试图片放大、关闭按钮、Esc、焦点返回、背景点击关闭、保存下载、图片失败回退；没有生成二维码，没有改变正式配置。结果见 `qr-checks.json`。
