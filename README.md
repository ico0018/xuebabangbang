# 学霸帮帮（XuebaBangBang）

一个面向学生和家长的实用学习网站，集合简单、好用的小工具、趣味小测试和学习建议，让学习中的小问题更容易解决。

> 项目正在起步阶段。第一阶段将优先完成首页和工具页，暂不提供注册、登录功能。

## 项目愿景

学霸帮帮希望成为一个轻量、友好、随手可用的学习助手。用户无需注册即可打开工具并立即使用，也可以浏览适合不同学习场景的内容和建议。

## 第一阶段功能

### 首页

- 展示热门及推荐工具
- 按学习场景快速查找工具
- 展示最新工具和学习内容
- 提供清晰的分类入口

### 工具页

- 浏览全部学习工具
- 按学科、年级或用途筛选
- 查看工具说明并直接使用
- 支持后续持续添加新的小工具和小测试

## 计划中的内容

- 语文学习工具
- 英语学习工具
- 数学学习工具
- 趣味知识测试
- 学习方法与经验分享
- 建议与讨论区
- 收藏、个人记录等账户功能

## 当前开发范围

当前版本只包含公开访问的首页和工具页：

- 不需要注册或登录
- 不收集用户账户信息
- 优先保证移动端和桌面端都能方便使用
- 先完成核心浏览与工具体验，再逐步扩展社区功能
